# EvoTools 🔬
A collection of bioinformatics scripts to aid in the identification and analysis of viral genes.

# Installation
The best way to run these scripts is within a dedicated Conda environment. This ensures all software dependencies are handled correctly and your analysis is reproducible. The provided EvoTools.yaml file will set up everything you need.
If you don't have Conda,is higly recommad to install it with Miniforge.
You can download and install the latest version of Miniforge for your specific OS from the git repository: https://github.com/conda-forge/miniforge/releases

## 1. Clone the present repository

````bash
git clone https://github.com/matheus-cosentino/EvoTools.git
````

## 2. Create the Conda Environment
From your terminal, navigate to the EvoTools directory and run:

````bash
conda env create -f EvoTools.yaml
````

## 3. Activate your Conda env

````bash
conda activate EvoTools
````

# Scripts in this Repository
## Extract_Fastas_Diamond.py
This script takes the output from a DIAMOND search (outfmt 6 format) and the original nucleotide FASTA file (e.g., your contigs) to extract the specific regions that had a significant hit. This saves you from manually finding and clipping these sequences.

````bash
python Extract_Fastas_Diamond.py --diamond <INPUT_DIAMOND_FILE> --fasta <INPUT_FASTA_FILE> --output <OUTPUT_FILE>
````


```console
--diamond: The path to your DIAMOND output file (in tab-separated outfmt 6 format).

--fasta: The path to the original query FASTA file used in the DIAMOND search.

--output: The name of the output FASTA file where the extracted sequences will be saved}
```

## backTranslate.py
This script automates the process of back-translating a protein alignment into a corresponding nucleotide alignment. It takes a protein alignment and the corresponding unaligned nucleotide sequences and produces a FASTA file of the aligned nucleotide sequences, correctly preserving gaps and codons.

````bash
python backTranslate.py -ali <AMINO_ACID_ALIGNMENT> -nt <NUCLEOTIDE_SEQUENCES> -out <OUTPUT_ALIGNMENT>
````


````console
-ali: The input aligned amino acid FASTA file.

-nt: The original unaligned nucleotide FASTA file. Note: The sequence IDs must match the IDs in the amino acid file.

-out: The name of the output file for the resulting nucleotide alignment.
````

## Plot_Tree.R
This R script offers a easy and customizable way to visualize phylogenetic trees using ggtree. It annotates the tree with metadata (e.g., host, country) and is designed to work with trees generated by IQ-TREE2 (using UFBoot and SH-aLRT values for node support).

```` bash
Rscript Plot_Tree_cmd.R -t <TREE_FILE> -m <METADATA_FILE> -o <OUTPUT_FILE> [OPTIONS]
````

````console
Required Arguments:

-t, --tree: Path to the input tree file (e.g., in Newick format).

-m, --metadata: Path to a tab-separated metadata file.

-o, --output: Path for the output plot file (e.g., My_Tree.svg).

Common Optional Arguments:

--tips_file: Provide a .txt file with one tip label per line to plot a subtree of only those tips.

--id_column: The column in your metadata file that matches the tree tip labels (Default: "Acc").

--color_column: The metadata column to use for coloring the tip points (Default: "Genus").

--species_column: The metadata column to use as the tip labels on the tree (Default: "Species").

-l, --layout: The tree layout to use (e.g., circular, fan). (Default: rectangular).
``````
